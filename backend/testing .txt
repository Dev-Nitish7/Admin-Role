## ✅ 1. `users` Table

```sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  username VARCHAR(100) UNIQUE NOT NULL,
  password VARCHAR(255) NOT NULL,
  role VARCHAR(20) DEFAULT 'user' CHECK (role IN ('user', 'admin')),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## ✅ 2. `user_files` Table

```sql
CREATE TABLE user_files (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
  filename TEXT NOT NULL,         -- Original file name
  fileurl TEXT NOT NULL,          -- Azure Blob Storage URL (with SAS if private)
  blobname TEXT NOT NULL,         -- Blob name in Azure (used to generate SAS)
  uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## ⚙️ Optional Reset Script

To clean and rebuild the tables during development:

```sql
DROP TABLE IF EXISTS user_files;
DROP TABLE IF EXISTS users;

-- Then re-run the two CREATE TABLE statements above
```

## 🔑 Authentication Routes (`/api/auth`)

### ✅ 1. Register a User
**POST** `http://localhost:5000/api/auth/register`  
**Body (JSON):**
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "password123"
}
```

---

### ✅ 2. Login as User or Admin
**POST** `http://localhost:5000/api/auth/login`  
**Body (JSON):**
```json
{
  "email": "john@example.com",
  "password": "password123"
}
```

**Returns:** `{ token: "JWT_TOKEN_HERE" }`

⏩ Use this token in all protected requests (headers):
```
Authorization: Bearer JWT_TOKEN_HERE
```

---

### ✅ 3. Get Current User Info
**GET** `http://localhost:5000/api/auth/me`  
**Headers:**
```
Authorization: Bearer JWT_TOKEN_HERE
```

---

## 🛡️ Admin Routes (`/api/admin`) – Requires admin role

> Must manually change user's role in DB if you want to test this. Example:
```sql
UPDATE users SET role = 'admin' WHERE email = 'john@example.com';
```

---

### ✅ 4. Get All Users
**GET** `http://localhost:5000/api/admin/users`  
**Headers:**
```
Authorization: Bearer JWT_TOKEN_HERE
```

---

### ✅ 5. Update User Info
**PUT** `http://localhost:5000/api/admin/user/:id`  
Replace `:id` with actual user ID.  
**Body (JSON):**
```json
{
  "name": "Updated Name",
  "email": "new@example.com"
}
```

---

### ✅ 6. Change User Role
**PUT** `http://localhost:5000/api/admin/user/:id/role`  
**Body (JSON):**
```json
{
  "role": "admin"  // or "user"
}
```

---

### ✅ 7. Delete a User
**DELETE** `http://localhost:5000/api/admin/user/:id`  
No body required.

---

## 📁 File Routes (`/api/files`)

### ✅ 8. Upload File (authenticated)
**POST** `http://localhost:5000/api/files/upload`  
**Headers:**
```
Authorization: Bearer JWT_TOKEN_HERE
Content-Type: multipart/form-data
```
**Body (form-data):**
- **Key:** `file`  
- **Type:** File  
- **Value:** Select a file from your system

---

### ✅ 9. Get Logged-In User’s Files
**GET** `http://localhost:5000/api/files/myfiles`  
**Headers:**
```
Authorization: Bearer JWT_TOKEN_HERE
```

---

### ✅ 10. Get All Files (authenticated users only)
**GET** `http://localhost:5000/api/files/allfiles`  
**Headers:**
```
Authorization: Bearer JWT_TOKEN_HERE
```
